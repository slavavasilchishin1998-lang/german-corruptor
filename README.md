
# 🇩🇪 GERMAN-CORRUPTOR 💥

A chaotic German text destruction tool.

## Features
- Article randomizer
- Word scrambling
- Letter corruption
- Sentence chaos
- Maximum destruction mode

## Usage

```bash
python german_corruptor.py "Der Hund ist sehr schön"
```

Maximum chaos:

```bash
python german_corruptor.py "Der Hund ist sehr schön" --chaos 100
```

## Warning
This tool intentionally destroys German grammar
and spelling. It is NOT a grammar corrector.
